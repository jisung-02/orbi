# 최적화 검증 — 2026-09-05

Apple M2, macOS arm64. 아래 수치는 개별 코드 경로의 측정치이며 앱 전체 CPU/RSS 감소율을 의미하지 않습니다. 이 검증에서는 전체 GUI 인스턴스의 전후 CPU/RSS를 측정하지 않았습니다.

| 경로 | 이전 | 이후 | 측정 방식 |
|---|---:|---:|---|
| 디스크 여유 공간 조회 | 2,018,537 ns / 49,139 B / 113 allocs | 606.5 ns / 2 B / 1 alloc | Go 벤치마크 3회 중앙값 |
| 반복 호버용 좌표 준비 | 412 ns / 496 B / 5 allocs | 2.188 ns / 0 B / 0 alloc | 설정이 바뀌지 않은 캐시 경로, 3회 중앙값 |
| 네이티브 타이머 갱신 1,000회 | 1.334초 | 약 0.004초 | 동일 Swift UI 테스트 실행, 비최적화 테스트 빌드 |

좌표 캐시는 초기화와 위젯 표시 설정 변경 시 다시 계산합니다. 창 이동은 캐시된 로컬 좌표에 창 원점을 더하므로 재계산하지 않습니다.

## 제거한 반복 작업

- Go/Rust 모니터는 창이 닫히면 CPU·메모리·네트워크·배터리·디스크를 수집하지 않습니다. 창 재개 후 첫 CPU/네트워크 값은 0으로 기준점을 잡고 이후 2초 간격으로 갱신합니다.
- Go 디스크 조회는 `df` 프로세스 실행 대신 `statfs`를 사용합니다. 배터리 조회는 15초 캐시를 적용합니다.
- Go 터미널 전송기는 출력 알림이 있을 때만 실행하고 50ms 동안 모아 전송합니다. 출력 없는 세션의 초당 20회 깨우기를 제거했습니다. EOF에서는 마지막 출력 전송 후 종료 이벤트를 보냅니다.
- 네이티브/웹 타이머는 정지·일시정지 상태에서 로컬 틱을 예약하지 않습니다. 카운트다운 갱신에서 버튼/팝오버 재생성을 제거했습니다.
- 오브 호버는 펼친 상태 25ms, 접힌 상태 60ms, 숨김 상태 250ms 간격입니다. 등장 애니메이션은 기존 45ms 순서를 유지합니다.
- 포모도로는 페이즈가 바뀔 때만 저장용 객체를 만들고, 네이티브 고빈도 진단 로그는 `DU_DEBUG=1`에서만 출력합니다.
